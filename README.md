# SPARC: Scenario Planning and Reasoning for Automated C Unit Test Generation

**Description** — <ins>Background</ins>: Automated unit test generation for C remains a formidable challenge due to the semantic gap between high-level program intent and the rigid syntactic constraints of pointer arithmetic and manual memory management. While Large Language Models (LLMs) exhibit strong generative capabilities, direct intent-to-code synthesis frequently suffers from the leap-to-code failure mode, where models prematurely emit code without grounding in program structure, constraints, and semantics, producing non-compilable tests, hallucinated function signatures, low branch coverage, and semantically irrelevant assertions that cannot properly capture bugs. <ins>Aims</ins>: We aim to bridge this semantic gap by aligning LLM reasoning with program structure to generate compilable, high-coverage, and semantically meaningful unit tests for C, particularly for functions where symbolic execution struggles with floating-point semantics, hash computations, or path explosion. <ins>Method</ins>: We introduce SPARC, a neuro-symbolic, scenario-based framework comprising four stages: (1) Control Flow Graph (CFG) analysis, (2) an Operation Map that grounds LLM reasoning in validated utility helpers, (3) path-targeted test synthesis, and (4) an iterative, self-correction validation loop using compiler and runtime feedback to surface C-specific failures such as memory ownership violations, address truncation, and allocator misuse. We evaluated SPARC on 59 C subjects spanning algorithmic implementations and real-world projects, comparing it against a vanilla DeepSeek prompting baseline using an iterative repair loop and against the symbolic execution tool KLEE. <ins>Results</ins>: SPARC outperforms the DeepSeek baseline by 31.36% in line coverage, 26.01% in branch coverage, and 20.78% in mutation score, while matching or exceeding KLEE on complex subjects. The framework retains 94.3% of tests through iterative repair and produces tests with significantly higher developer-rated readability and maintainability. <ins>Conclusions</ins>: By aligning LLM reasoning with program structure through scenario-based decomposition and symbolic grounding, SPARC offers a practical and extensible approach to LLM-based C unit test generation. It is particularly effective for functions where symbolic execution falters due to floating-point semantics, hash computations, or path explosion, demonstrating that neuro-symbolic integration can mitigate the leap-to-code failure mode endemic to direct LLM code synthesis.
